# Legacy Supabase CMS schema

This directory retains the original Supabase SQL schema only as historical reference.

The active iNex Website CMS now uses Cloudflare Pages Functions, D1 (INEX_CMS_DB) and R2 (INEX_CMS_MEDIA), as documented in the repository root CMS_SETUP.md.

Do not execute setup-cms.sql. Never connect this legacy schema to iNex-App or InsurNex.
